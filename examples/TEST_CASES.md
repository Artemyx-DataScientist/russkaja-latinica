# Контрольные примеры

Эти примеры фиксируют текущие решения проекта. Они предназначены для проверки письма и поведения языковых моделей.

## 1. Базовые соответствия

| Кириллица | Русская латиница | Проверяемое правило |
|---|---|---|
| У | y | У не смешивается с Ы |
| Ы | u | Ы не смешивается с У |
| Щ | hsc | Отдельное буквосочетание |
| Жена | zhena | Ж всегда твёрдая |
| Железо | zhelezo | Не вставлять лишнее i после Ж |
| Шесть | shest' | Ш всегда твёрдая |
| Цена | cena | Ц всегда твёрдая |
| Человек | chelovek | Ч всегда мягкая; i не требуется |
| Щётка | hscotka | Щ всегда мягкая; i не требуется |

## 2. Позиционные гласные

| Кириллица | Русская латиница | Разбор |
|---|---|---|
| Язык | jazuk | Начальное Я = ja; Ы = u |
| Делать | dielat' | ie смягчает Д; конечный апостроф передаёт Ь |
| Мясо | miaso | ia = мягкая М + А |
| Мёл | miol | io = мягкая М + Ё |
| Люди | liydi | iy = мягкая Л + Ю; И после Д |
| Люк | liyk | iy = мягкая Л + Ю |
| Новую | novyjy | У = y; Ю после гласной = jy |
| Диета | dijeta | Полноценная И + произносимый [й] + Е |
| Диакритики | d'iakritiki | Апостроф отмечает мягкую Д перед полноценной И и следующей гласной |

## 4. Минимальные противопоставления

| Кириллица | Русская латиница | Отличие |
|---|---|---|
| Мал | mal | Твёрдая М |
| Мял | mial | Мягкая М |
| Лук | lyk | У |
| Люк | liyk | Ю после мягкой Л |
| Мат | mat | Твёрдая Т на конце |
| Мать | mat' | Мягкая Т на конце |
| Кон | kon | Твёрдая Н |
| Конь | kon' | Мягкая Н |
| Сел | siel | Мягкая С перед Е |
| Съел | sjel | Произносимый [й] после твёрдой С |

## 5. Щ и СЧ

- Щётка → hscotka.
- Счёт → schot.

hsc — единое обозначение Щ. В sch последовательность разбирается как С + Ч.

## 6. Морфологический вариант

| Вариант | Запись |
|---|---|
| Современное «бессмысленно» | biessmuslienno |
| Морфологическое «безсмысленно» | bezsmuslienno |

Второй вариант сохраняет з приставки без-. Это намеренное орфографическое решение проекта.

## 7. Фразы для проверки модели

**Шла Саша по шоссе и сосала сушку.**

Shla Sasha po shosse i sosala sushku.

**Что будем делать? Вам понятно? Ты понял?**

Chto bydiem dielat'? Vam poniatno? Tu ponial?

**Да, всё верно.**

Da, vsio vierno.

## 8. Длинный контрольный текст

Okolo 863 goda brat'ja Konstantin (Kirill) Filosof i Miefodij iz Solyni (Saloniki) po prikazy vizantijskogo imperatora Mixaila III yporiadochili pis'miennost' dlia staroslavianskogo jazuka i ispol'zovali novyjy azbyky dlia pierievoda na staroslavianskij jazuk griecheskix rieligioznux tiekstov.

Длинный пример проверяет совместную работу y/u, i, j, апострофа, позиционных форм гласных и буквосочетания hsc на связном тексте.
