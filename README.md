# Русская латиница

**Русская латиница** (*russkaja-latinica*) — проект самостоятельной ASCII-орфографии для современного русского языка.

Цель проекта — дать возможность писать по-русски латинскими буквами без диакритики, специальных национальных символов и искусственного подчинения русского произношения английским правилам чтения.

Это не ISO-транслитерация и не механическая замена каждой кириллической буквы одним латинским знаком. Написание зависит от произношения и позиции звуков в слове.

## Статус

- Версия спецификации: **0.1.0-draft**
- Статус: **рабочий проект**
- Основной принцип: стандартные ASCII-буквы и апостроф; без диакритики.
- Правила, которые ещё требуют проверки на корпусе, явно отмечаются как предварительные.

## Основные решения

- **y** передаёт У, **u** передаёт Ы.
- **j** обозначает произносимый звук [й].
- **je, jo, jy, ja** передают йотированные гласные там, где произносится [й].
- **i** может быть полноценной И или немым позиционным маркером мягкости парной согласной.
- Мягкость обозначается через **i** только у согласных, имеющих противопоставление по твёрдости и мягкости.
- Ж, Ш, Ц всегда твёрдые; Ч и Щ всегда мягкие. Дополнительный маркер мягкости после них не ставится.
- **hsc** — единое буквосочетание для Щ.
- Апостроф обозначает мягкость там, где её нельзя выразить позиционным **i**, и передаёт Ь.
- Ъ отдельным знаком не передаётся; произносимый [й] сохраняется через **j**.
- Допускается морфологическое написание, сохраняющее состав морфем, например **bezsmuslienno**.

## Пример

> Shla Sasha po shosse i sosala sushku.

> Okolo 863 goda brat'ja Konstantin (Kirill) Filosof i Miefodij iz Solyni (Saloniki) po prikazy vizantijskogo imperatora Mixaila III yporiadochili pis'miennost' dlia staroslavianskogo jazuka i ispol'zovali novyjy azbyky dlia pierievoda na staroslavianskij jazuk griecheskix rieligioznux tiekstov.

## Принцип использования

Если пользователь просит писать русской латиницей или сам начинает писать на ней, следует продолжать на той же орфографии. По умолчанию не нужно добавлять пояснения, обратную кириллическую запись или таблицу транслитерации.

Система развивается. Неоднозначные случаи следует проверять и документировать, а не закрывать произвольными правилами.
